# RentAttire Frontend Project

This is the frontend prototype for the RentAttire e-commerce web application, built as a university Web Application Development project.

## Project Description
RentAttire allows customers to discover and rent stylish attire for weddings, parties, and formal events without the high cost of purchasing.

## Technologies Used
- HTML5 (Semantic Structure)
- CSS3 (Custom styling, CSS Variables, Responsive Design via Media Queries)
- Vanilla JavaScript (DOM Manipulation, Form Validation, localStorage for Cart, filtering)
- SVG (Icons and placeholders)
- *Note: Built entirely without external frameworks or libraries (no Bootstrap, Tailwind, React, jQuery, etc.)*

## File Structure
- `index.html`: Home page
- `products.html`: Product catalog with simple filtering
- `product-details.html`: Single product view with rental date calculation
- `cart.html`: Shopping cart (uses localStorage)
- `login.html` & `register.html`: Authentication mockups with validation
- `account.html`, `history.html`, `tracking.html`: User dashboard and orders
- `contact.html`, `about.html`, `privacy.html`, `terms.html`: Informational pages
- `css/style.css`: All styling
- `js/script.js`: All client-side logic
- `images/`: SVG images/icons

## How to Run
Simply open `index.html` in any modern web browser. No server setup is required for this frontend prototype.

## Future Enhancements
This prototype is designed to easily integrate with a PHP backend and MySQL database in the future. Ajax calls and form submissions have been prepared for this integration.
